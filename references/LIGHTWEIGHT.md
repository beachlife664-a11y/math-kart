# 轻量化基线与质量门槛

## 结果

| 项目 | 优化前 | 优化后 | 降幅 |
|---|---:|---:|---:|
| 新版本 Git 追踪树 | 约 747.45 MB | 约 31.96 MB | 约 95.7% |
| `public/` 正式运行资源 | 约 48.22 MB | 约 25.52 MB | 约 47.1% |
| `public/models/*.glb` | 约 39.21 MB | 约 16.51 MB | 约 57.9% |

这里的“追踪树”是新版源码下载所对应的文件总量，不包含 `node_modules/`、`dist/` 或旧 Git 历史。普通提交不会清除旧历史中的大对象；如要缩小完整克隆的 `.git/`，必须另行评估历史重写和强制推送，不能把源码树降幅宣称为历史降幅。

## 采取的措施

1. 31 个正式 GLB 使用高等级 Meshopt 压缩，不减三角形、不删除正式车辆或地标、不替换既有贴图。
2. 所有 GLTFLoader 统一配置 Meshopt decoder，桌面、手机和地标共用相同加载能力。
3. 更新 `assets/runtime-manifest.json` 中全部运行文件的字节数与 SHA-256。
4. 原始建模中间稿、历史截图、测试录像和可再生成的 QA 输出仅从 Git 新树移除，本机文件保留并通过 `.gitignore` 防止重新提交。
5. 保留完整源码、正式资源、音频母带、生成日志、制作文档、测试脚本和 CI，不通过删玩法或删验收能力换体积。

## 验证记录

- 31 个模型压缩前后的节点、网格、材质、贴图、动画和三角形数量一致。
- `npm run verify:assets`：65/65 运行资源哈希一致。
- TypeScript、ESLint 和生产构建通过。
- Chromium 生产构建中，桌面 active-play、桌面 cliff、手机 active-play、手机 cliff 四组真实 WebGL 捕获均非空、无浏览器错误且符合既有渲染预算。
- 最终 v13 合并版 `npm run verify:local` 全部通过：11 项玩法/布局/镜头、2 项音频/碰撞、真实不对称答题镜头、Chromium/Firefox/WebKit、普通生产入口和四组桌面/手机画布检查。
- 在同一 v13 代码提交下分别切换原始模型与 Meshopt 模型，以种子 42 重拍四组画面；平均像素差为 0.0068–0.0956/255，人工复核未见可见场景、车辆、材质或布局差异。证据保留在本机 `artifacts/v14-lightweight/`。
- 压缩前后截图进行像素对比和人工复核，场景、车辆、材质与布局保持一致。

后续修改模型时不得只检查 CLI 退出码；必须重复结构核对、资源哈希、生产预览和真实画面回归。
