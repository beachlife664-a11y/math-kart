# 玩法与界面约束

## 核心玩法

- 开局选择 1 人或 2 人同屏。每名玩家对应一辆真实玩家赛车；双人模式不得用 AI 赛车替代 P2。
- 驾驶、跟车、超车、避障、漂移和道具时机全自动。玩家通过独立数学题获得加速、连对能量和路段奖励。
- 答错时显示正确答案并失去本次奖励，不停车、不倒退。所有真实玩家完赛后生成排名。
- 赛道依次为海滨、港口、山崖、水晶洞穴和跨海大桥，共两圈。

## 输入

| 行为 | 桌面 | 触摸设备 |
| --- | --- | --- |
| 数学输入 | P1 主键盘数字区；P2 右侧小键盘 | 各自屏幕数字键盘 |
| 提交与修改 | P1 Enter / Backspace；P2 小键盘 Enter / Delete | 确认、清空和退格按钮 |
| 暂停 | P / Esc 或暂停按钮 | 暂停按钮 |
| 静音 | M 或声音按钮 | 声音按钮 |
| 车库查看 | 拖动旋转、滚轮缩放 | 单指拖动 |

不得添加驾驶方向键或把答题输入改成选项按钮，除非用户明确要求改变玩法。

## 布局与镜头

- 桌面上方约 60% 为真实 3D 赛道，下方约 40% 为独立答题区。双人面板并排，单人面板居中。
- 使用大算式和大数字按键。长算式、倒计时和暂停状态不得破坏布局或遮挡赛道。
- 手机保留赛道与完整答题操作，不因缩小视口删除输入键或车辆视野。
- 双人接近时共享镜头；距离拉开后稳定分为左右独立追踪画面；追赶后自动合并。
- 起步镜头减少天空占比；近距起点拱门渐隐。不得通过无限拉远中点镜头容纳两名玩家。

## 修改后的最低验收

- 用真实数字输入分别驱动 P1 拉开和 P2 追赶，确认分屏与合并、车辆可见性和面板无遮挡。
- 检查单人、双人、手机、紧凑桌面、长算式、倒计时、暂停和最终排名。
- 通过普通生产入口验证，不仅检查开发服务器或测试钩子画面。
