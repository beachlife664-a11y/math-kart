# 算力狂飙 v4 · 全场景精细美术方案

## 用户反馈与目标

v3 的地标已有提升，但真实驾驶画面仍暴露出底座过于简单：赛道是平面网格，赛车和驾驶员缺少统一的精细结构，远山是大块低细节形体，草地是单色平面，白云是球体组合，水面缺少动态。v4 不再只增加地标，而是对所有主要可见层进行替换或重做。

目标：保持五车、五段两圈、答案-only 自动竞速不变，让驾驶时看得见的车身、驾驶员、路面、路肩、护栏、植被、山水、天空和近景道具都具有明确结构、材质和尺度。

## 统一美术方向

“精品海岛拉力赛”：真实可辨的赛车结构与自然环境，采用明亮但不过曝的配色；珊瑚橙、海青和奶油白作为赛事识别色。模型不追求照片级，而追求完整轮廓、合理装配、分层材质和近景可读性。重复物体必须共享几何与材质，不能靠堆高面数制造“精细”。

## 分层资产清单

| 层级 | 当前问题 | v4 方案 |
|---|---|---|
| 赛道 | 单平面、重复灰纹、路肩是方盒 | 带横拱与路缘高度的连续网格；真实米制 UV；沥青颗粒/裂缝/修补/刹车痕；倒角路缘、排水槽、反光钉、接缝和加速/跳台标记 |
| 赛车 | 车身细节不统一，车轮结构简单 | 五张独立车身参考 → 五个 Hyper3D 车身；独立轮胎胎纹、轮毂、刹车盘、悬挂臂、排气与车灯；统一尺寸和枢轴 |
| 驾驶员 | 胶囊身体与球形头盔 | 坐姿精细驾驶员实模：头盔、面罩、赛车服、手套、靴子、手臂握姿；独立方向盘与车身倾身/庆祝动作 |
| 起跑区 | 看台/车库主要是盒子 | 精细看台与维修区建筑、座椅、栏杆、支撑、楼梯、旗帜、观众剪影和起跑灯结构 |
| 山与岩体 | 远山低细节色块 | 多频高度场与山脊轮廓、坡度分层材质、岩层/草地/沙地纹理、近景岩体和远岛层次 |
| 草地植被 | 平面绿色+少量十二面体 | 实例化多叶草簇、花丛与灌木；近景使用完整叶片几何，远景采用低成本 LOD；风摆和色彩变化 |
| 天空白云 | 球体云和简单渐变 | 大气渐变、太阳/薄雾、立体云簇模型与远景云层；云有体积、明暗和尺度变化 |
| 水面 | 单张蓝色平面 | 细分水面、顶点波浪、动态法线、菲涅耳反射、海岸线泡沫与瀑布水雾 |
| 护栏/路障 | 方盒与圆锥 | 连续双梁护栏、立柱、连接件、反光板、轮胎墙、橡胶堆和带反光条的交通锥 |
| 已有地标 | 已有 Hyper3D 模型 | 保留港口、灯塔、桥塔、洞口和棕榈，重新校正周边地形、材质与遮挡，不重复生成 |

## 新 Hyper3D 生产范围

1. 五个车身：Comet 珊瑚火箭、Bolt 黄色方程式、Sprout 薄荷越野、Nova 紫星科幻、Reef 海青街头。
2. 一个高细节坐姿驾驶员，配套五色材质变体。
3. 看台/维修区组合建筑。
4. 立体云簇。
5. 草叶与小花组成的近景植被簇。
6. 海岛层状山岩模块。
7. 轮胎墙路障。

道路与连续地形必须服从真实赛道样条和碰撞，因此采用代码网格与 PBR 材质，而不是用无法对齐玩法的整条静态生成赛道替代。水面和天空采用实时渲染系统，避免把大面积环境做成不可控的高面数模型。

## 性能与整合约束

- 先验证“海滨直道—港口—山崖”代表段，再扩展所有重复资产。
- 车身与驾驶员只负责视觉，碰撞代理和现有自动竞速模拟保持不变。
- 新模型均检查尺寸、枢轴、朝向、面数、材质、纹理和独立预览；失败版本不得进入正式场景。
- 重复草、云、轮胎、护栏、观众和岩石使用 `InstancedMesh` 或共享几何/材质。
- 手机保留主要模型轮廓，降低纹理、面数、草密度、云数量和波浪细分。
- 起始预算沿用桌面 300 calls / 750k triangles、手机 150 calls / 300k triangles；若精细资产确需调整，必须记录实测原因，不能用修改断言掩盖性能问题。
- 最终必须重新通过生产构建、玩法、移动、三浏览器、完整比赛和动态画面检查。

## 验收重点

1. 玩家能清楚看见五台车的不同结构，而不是只换颜色。
2. 驾驶员有完整头盔、服装、四肢和握姿，不再是白色胶囊。
3. 路面有细微材质与功能结构，路肩和护栏有真实装配关系。
4. 草地、山岩、白云和水面在近景/中景/远景都有明确层次，不再是单色底座。
5. 只点击答案仍能完成两圈比赛，镜头无持续穿模，手机预算与布局可接受。
