# 仓库内容与取舍

## 核心目录

| 路径 | 内容 | 运行是否必需 |
|---|---|---|
| `src/` | 全部 React / TypeScript / Three.js 源码 | 是（构建） |
| `public/` | 65 个正式模型、贴图、音频、缩略图和 JSON 清单 | 是 |
| `assets/` | 山体原模/参考、音频母带、真实生成日志、运行资源哈希 | 复刻资料；运行哈希用于校验 |
| `scripts/` | 安装、预览、验证、模型优化、捕获与 QA | 是 |
| `tests/` | 玩法与音频/碰撞测试 | 验证时需要 |
| `docs/` | 复刻、规则、架构、制作、资产、音频和发布文档 | 文档 |
| `artifacts/art-v6/` | 七车原始建模包、参考图、LOD、预览和任务记录 | 建模资料 |
| `artifacts/art-v5/` | 卡通赛车/环境制作过程、原模、优化版、参考和预览 | 建模资料 |
| `artifacts/art-v3/` | 当前港口原始模型及首轮参考资料 | 建模资料 |
| `artifacts/v9-final/` | 当前完整比赛、岩石修复、桌面/手机和浏览器证据 | 验收资料 |
| `artifacts/reproduction/` | 用户在全新环境运行验证后生成的报告 | 输出目录 |

## 已保留的“全部复刻所需内容”

- 当前版本全部源码、配置和 lockfile。
- 正式运行资源及每个文件的 SHA-256。
- 当前七车原始 GLB、桌面/手机 LOD、参考图和 Hyper3D 任务记录。
- 当前地标/环境的生成资料、原始模型和优化过程。
- 山体确认图、原始坡崖和变体。
- 11 个音频母带与正式 WAV。
- 清洗后的真实图像、Hyper3D 和音频生成提示词/参数。
- 设计简报、历史进度、最终验收和当前完整比赛录像。
- 可独立运行的安装、预览、测试、检查和 CI 工作流。

## 明确不纳入的内容

- `node_modules/`、`dist/`、Playwright 缓存、浏览器缓存：全部可重建。
- 个人电脑绝对路径、OAuth 数据、密钥、签名 URL、内部运行轨迹。
- 重复旧录像、失败页面捕获、被替换模型的备份副本和临时中间文件。
- 未形成当前资产且无法确认状态的付费任务结果；相关不确定性在历史进度中如实说明。

这些取舍不影响当前版本 1:1 运行、建模检查或二次创作。所有运行和制作资料都以文件形式随仓库提供，而不是通过外部临时链接引用。
