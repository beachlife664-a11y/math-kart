# 仓库内容与轻量化取舍

## 核心目录

| 路径 | 内容 | 运行是否必需 |
|---|---|---|
| `src/` | 全部 React / TypeScript / Three.js 源码 | 是（构建） |
| `public/` | 65 个正式模型、贴图、音频、缩略图和 JSON 清单 | 是 |
| `assets/` | 音频母带、真实生成日志、运行资源哈希 | 运行哈希用于校验；其余为复刻资料 |
| `scripts/` | 安装、预览、验证、模型优化、捕获与 QA | 是 |
| `tests/` | 玩法与音频/碰撞测试 | 验证时需要 |
| `docs/` | 复刻、规则、架构、制作、资产、音频和发布文档 | 文档 |
| `artifacts/*.md` | 设计、美术方向、制作过程和验收说明 | 文档 |

## 保留的完整运行复刻内容

- 当前版本全部源码、配置和 lockfile。
- 正式运行资源及每个文件的 SHA-256。
- 11 个音频母带与正式 WAV。
- 清洗后的真实图像、Hyper3D 和音频生成提示词/参数。
- 设计简报、历史进度与验收说明。
- 可独立运行的安装、预览、测试、检查和 CI 工作流。

## 不再随 GitHub 分发的大型资料

- `artifacts/art-v*/`：原始 GLB、参考图、任务记录、LOD 中间版本和建模预览。
- `artifacts/v*/`：历史截图、完整比赛录像和阶段性验收输出。
- `artifacts/reproduction/`：可由验证脚本重新生成的报告、截图和录像。
- `assets/models/`、`assets/concepts/`：山体原模、LOD 中间稿和参考图。

这些目录保留在制作者本机，并由 `.gitignore` 防止重新误提交。`node_modules/`、`dist/`、Playwright 与浏览器缓存同样可重建，不纳入版本控制。

轻量化不移除任何正式车辆、地标、贴图、音频、玩法或测试能力。新克隆仓库仍可离线运行当前游戏；需要重新验收时执行脚本即可生成新证据。个人电脑绝对路径、OAuth 数据、密钥、签名 URL 和内部运行轨迹始终不纳入仓库。
