# 来源、授权与分发边界

## 代码

仓库内为本项目编写的 TypeScript、JavaScript、CSS、HTML 和构建/测试脚本按根目录 `LICENSE` 的 MIT 条款提供。MIT 许可不改变第三方包、生成平台或素材自身的条款。

## npm 依赖

React、Three.js、Vite、Playwright、meshoptimizer 及其他依赖分别遵循其自身许可证。`npm ci` 会下载依赖，许可证位于对应 npm 包中；分发包含依赖的构建产物时应保留必要的第三方声明。

## Hyper3D 生成资产

七款赛车、港口主楼、灯塔、渔船、棕榈、岩体、洞穴和桥塔等 GLB 由项目制作过程中使用 Hyper3D Rodin 图生 3D 生成，再进行减面、贴图压缩、尺寸/枢轴校准与游戏整合。参考图、任务 ID、原模和优化版随仓库保留。

这些文件不是声称来自公共领域或开源模型库。公开或商业再分发前，仓库发布者应自行确认其 Hyper3D 账号和当时服务条款是否允许相应使用；本仓库不为平台生成资产额外授予第三方权利。

## 图像生成素材

赛车、地标、山体等参考图由项目图像生成流程制作，实际提示词和迭代保存在 `assets/generation-log.json`。同样应遵守所用生成服务的分发条款。

## 音频

`assets/audio/seed/` 中的 11 个母带来自 Seed Audio 生成流程，正式 WAV 经项目后处理。落地与引擎音为代码合成。公开或商业使用时，发布者应确认所用音频生成服务条款。

## 纹理与程序资源

道路、地表、护栏、支撑、海水、天空、植被、驾驶员分件、VFX 和合成音由项目代码生成或组合。`public/textures/` 为项目制作过程中形成的本地资源，不依赖运行时外部图库链接。

## 不包含

- 其他作者的开源模型包或付费素材包；
- 真实品牌车标、真实角色或真人声纹；
- 平台 API Key、OAuth 凭据、签名下载 URL；
- 对第三方生成资产“可无条件转售/再授权”的承诺。

如果你只需要个人或团队内部复刻，直接按 README 安装即可；如果要公开销售或重新授权素材，请先完成相应权利审查。
